Open Ended-Question: Answer

I would design the matchmaking system around a queue that stores each player or party with their skill rating, preferred mode, region or server location, and the time they entered the queue. When a player starts matchmaking, the system places them into the correct queue depending on the mode, such as 1v1, 2v2, or 3v3. The system would first try to match players with very similar skill ratings so the match feels fair, but if the player waits too long, the allowed skill range slowly becomes wider to reduce waiting time. For team modes, I would compare the total or average skill rating of each team instead of only comparing individual players, so a 3v3 match would not only check if all players are close in skill, but also if both teams have a balanced overall rating. I would also make sure parties stay together and are matched against another party or a team with a similar combined rating whenever possible.
